# Run bundle format v1 — served copy

`schema.json` in this directory is served verbatim at
`https://chatwright.dev/formats/run-bundle/v1/schema.json` (see
`../../../index.ts`, which imports it and re-serves it byte-for-byte with
`Content-Type: application/json`).

**Canonical source:** `formats/run-bundle/v1/schema.json` in
[`chatwright/chatwright`](https://github.com/chatwright/chatwright) (Go
package `bundle`, generated by `internal/schemagen` — see `bundle/bundle.go`'s
package doc comment and `bundle/schema_test.go`, which gates that repo's copy
against drift from the Go types).

This copy is **not** independently maintained: it is re-copied here from the
canonical source whenever the run-bundle format releases a change. The
release checklist in `chatwright/chatwright` owns that sync step — do not
hand-edit `schema.json` in this repository.

`page.ts` in this directory renders the human-readable format page at
`https://chatwright.dev/formats/run-bundle/v1`.
